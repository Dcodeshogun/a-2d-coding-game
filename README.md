# Return0  
A 2D action-puzzle game built using Phaser, JavaScript, and Aseprite.

## About
Return0 is a 2D side-scrolling game inspired by system glitches and digital decay.  
You play as **2B**, an android program reactivated inside a broken network, tasked with restoring lost system functions and eliminating corrupted machines.  
The game mixes fast-paced combat with short logic-based challenges that reward successful players with new abilities and upgrades.

## Features
- Playable 2B character with smooth movement and attack mechanics  
- Enemy AI featuring patrol, chase, and attack behaviors  
- Quiz encounters that appear after certain fights, unlocking abilities when answered correctly  
- HUD displaying player health, energy, and abilities  
- Pixel art environments and animations made in Aseprite  
- Background music and sound effects integrated via Phaser’s audio API  

## Tools and Technologies
- **Phaser 3** – Game engine  
- **JavaScript (ES6)** – Core language  
- **Visual Studio Code** – Main IDE  
- **GitHub** – Version control and issue tracking  
- **Aseprite** – Sprite and animation design
